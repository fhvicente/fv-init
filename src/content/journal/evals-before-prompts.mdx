Every LLM feature I ship starts the same way: twenty real inputs and what a good answer looks like.

<Callout title="Rule of thumb">If you can't say what good looks like, the model can't either.</Callout>

## Start small

Twenty cases catch most regressions. Grow the set when a bug escapes it.

```ts
for (const c of cases) {
    const out = await run(c.input);
    assert(judge(out, c.expected), c.name);
}
```
