## The problem

Support queues grow faster than teams. Most tickets repeat questions the docs already answer.

## What I built

A pipeline that classifies each ticket, retrieves the relevant docs with pgvector, and drafts a reply an agent can approve in one click.

<Callout title="Result">Median first response dropped from hours to minutes.</Callout>

```ts
const draft = await answer({ ticket, context: await retrieve(ticket.body, { k: 6 }) });
```

## What I learned

Evals came first. Every prompt change ran against a fixed set of real tickets before it shipped.
